---
description: Подключить свой магазин Wildberries — создать файл токена и проверить связь
---

Помоги ученику подключить магазин Wildberries к плагину. Действуй по шагам и после каждого шага коротко пиши, что сделано.

⛔ Токен в чат не принимай и не записывай сам. Если ученик всё же прислал токен в сообщении, скажи, что токен
лучше удалить в личном кабинете WB и выпустить новый, и продолжай без него.

1. Проверь, что установлен Node.js 18 или новее: `node -v`. Если команды нет или версия старше —
   объясни, что нужно поставить LTS-версию с nodejs.org, перезапустить Claude Code и вызвать команду снова.
2. Создай папку `~/.wb-plugin` и файл `~/.wb-plugin/keys.env` из шаблона `${CLAUDE_PLUGIN_ROOT}/keys.env.example`,
   если файла ещё нет. Существующий файл не перезаписывай. На macOS и Linux выставь права `chmod 600`.
   На Windows путь — `%USERPROFILE%\.wb-plugin\keys.env`.
3. Открой файл ученику в редакторе (macOS: `open -e`, Windows: `notepad`) и объясни, где взять токен:
   личный кабинет WB → Настройки → Доступ к API → «Создать новый токен». Тип — «Персональный».
   Отметить «Только на чтение» и категории: Контент, Аналитика, Цены и скидки, Статистика, Продвижение.
   Скопировать токен целиком — это длинная строка из трёх частей через точку.
   Попроси вписать его после `WB_API_TOKEN=`, сохранить файл и написать «готово».
4. После «готово» вызови инструмент `wb_check` и покажи результат. Если не хватает категорий — объясни, какие
   инструменты из-за этого не заработают, и что нужно выпустить новый токен с этими категориями.
   Если ошибка 401 — токен скопирован не целиком или истёк.
5. Когда проверка зелёная, предложи первый запрос: «Покажи воронку WB за прошлую неделю».
