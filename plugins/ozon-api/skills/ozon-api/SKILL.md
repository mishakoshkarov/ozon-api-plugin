# Данные Ozon через API

## Порядок
1. Первый вызов в разговоре — `ozon_check`. Если ключей нет, предложи команду `/ozon-api:ozon-setup`.
   ⛔ Никогда не проси прислать ключи в чат и не записывай их сам: ученик вписывает их в файл своими руками.
2. Возьми данные нужным инструментом. Полный ответ каждого инструмента лежит в файле (путь в конце ответа):
   для своих подсчётов читай этот файл, а не пересказ в чате.
3. В выводе называй источник, период и знаменатель каждого числа. Где данных нет — так и пиши: «нет данных», с причиной.

## Правила чтения цифр (без них выводы будут неверными)
- **Две схемы.** Наличие = FBO + FBS. Пустой склад FBO ещё не значит «товара нет», а ноль продаж — ещё не диагноз:
  сначала проверь остаток. Продажи сравнивай на днях, когда товар был в наличии.
- **Отправления ≠ заказы.** Один заказ может разбиться на несколько отправлений. `ozon_orders` считает и то и другое.
- **Штуки ≠ заказы.** `ordered_units` в воронке — это штуки.
- **Сумма заказов ≠ деньги к выплате.** Это цена в отправлении до отмен, возвратов, комиссии и логистики.
  Сколько придёт на счёт, по этим инструментам не считается.
- **Сессии магазина ≠ сумма сессий по SKU.** В разрезе по товарам одна сессия засчитывается нескольким SKU.
- **Без Premium Plus** воронка отдаёт только выручку и штуки — показы и корзины недоступны, это не ошибка.
  `/v1/analytics/data` лимитирован: не чаще раза в минуту, без подписки около 50 вызовов в сутки. Бери период сразу целиком.
- **Кластеры FBO:** `ads` и `idc` повторяются в строках одного SKU — по строкам их не складывать.
- **Реклама «Оплата за заказ»:** в `ozon_ads_stats` у неё есть расход, но заказы всегда нули. Убыточной её по этому отчёту не объявлять.
- **ДРР** в `ozon_ads_stats` — к рекламным заказам, а не ко всей выручке магазина. Называй, какой из двух считаешь.
- **Сравнение периодов** — только сопоставимых: одинаковая длина, одинаковые дни недели, не меняли ли цену, рекламу, контент.
  Рост или падение на коротком окне — гипотеза, а не вывод.
- **Пустая характеристика** в `ozon_product_content` ещё не дефект: часть полей Ozon заполняет сам.

## Чего плагин не делает
Не меняет цены, ставки, карточки и остатки — методов записи в нём нет. Если ученик просит что-то поменять,
объясни, где это сделать в личном кабинете, или подготовь значения для ручного ввода.
