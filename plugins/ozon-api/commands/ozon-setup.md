---
description: Подключить свой магазин Ozon — создать файл ключей и проверить связь
---

Помоги ученику подключить магазин Ozon к плагину. Действуй по шагам и после каждого шага коротко пиши, что сделано.

⛔ Ключи в чат не принимай и не записывай сам. Если ученик всё же прислал ключ в сообщении, скажи, что ключ
лучше перевыпустить в личном кабинете Ozon, и продолжай без него.

1. Проверь, что установлен Node.js 18 или новее: `node -v`. Если команды нет или версия старше —
   объясни, что нужно поставить LTS-версию с nodejs.org, перезапустить Claude Code и вызвать команду снова.
2. Создай папку `~/.ozon-plugin` и файл `~/.ozon-plugin/keys.env` из шаблона `${CLAUDE_PLUGIN_ROOT}/keys.env.example`,
   если файла ещё нет. Существующий файл не перезаписывай. На macOS и Linux выставь права `chmod 600`.
   На Windows путь — `%USERPROFILE%\.ozon-plugin\keys.env`.
3. Открой файл ученику в редакторе (macOS: `open -e`, Windows: `notepad`) и объясни, где взять ключи:
   - Seller API: личный кабинет Ozon → Настройки → API-ключи → «Сгенерировать ключ». Нужны Client ID и сам ключ.
   - Performance API для рекламы: личный кабинет → Продвижение → Performance API → создать аккаунт,
     нужны client_id и client_secret. Без них работает всё, кроме рекламы.
   Попроси вписать значения после знака `=`, сохранить файл и написать «готово».
4. После «готово» вызови инструмент `ozon_check` и покажи результат. Если ошибка 401 или 403 — ключ неверный
   или у него не хватает прав; если ошибка сети — проверить интернет и VPN.
5. Когда проверка зелёная, предложи первый запрос: «Покажи остатки FBO и FBS по всем товарам».
