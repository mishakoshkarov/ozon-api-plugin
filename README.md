# Плагины Ozon API и WB API для Claude Code

Подключают Claude Code к вашему магазину на Ozon и на Wildberries. После установки можно спрашивать в чате
обычными словами: «какие остатки по FBO и FBS», «сколько заказов было на прошлой неделе», «покажи воронку WB»,
«выгрузи характеристики и описание артикула 12.34», «как отработала реклама», «сколько WB перечислит за неделю».

Плагины **только читают** данные. Цены, ставки, карточки и остатки они не меняют.

## Как это устроено

```
Claude Code ──► локальный сервер плагина (Node.js на вашем компьютере) ──► API Ozon / API Wildberries
```

Сервер запускается сам вместе с Claude Code и работает на вашем компьютере. Ключи лежат в файле
на вашем компьютере. В чат они не попадают и никуда, кроме Ozon или WB, не отправляются.
Полные ответы сохраняются в папки `ozon-data` и `wb-data` в вашей домашней папке, в чат приходит сводка.

## Что нужно

- Claude Code (нужна платная подписка Claude Pro или выше).
- Node.js 18 или новее: скачать LTS-версию с nodejs.org. Проверка — команда `node -v` в терминале.
- Для Ozon — ключ Seller API, для рекламы ещё ключ Performance API. Для WB — один токен.

## Установка

В Claude Code добавьте каталог плагинов и поставьте нужные:

```
/plugin marketplace add mishakoshkarov/ozon-api-plugin
/plugin install ozon-api@mp-kurs
/plugin install wb-api@mp-kurs
```

Перезапустите Claude Code и подключите магазины:

```
/ozon-api:ozon-setup
/wb-api:wb-setup
```

Claude создаст файл для ключей и откроет его. Впишите ключи **в файл**, а не в чат, сохраните и напишите «готово».
Claude проверит подключение.

| | Файл ключей |
|---|---|
| Ozon | `~/.ozon-plugin/keys.env` (Windows: `C:\Users\<имя>\.ozon-plugin\keys.env`) |
| WB | `~/.wb-plugin/keys.env` (Windows: `C:\Users\<имя>\.wb-plugin\keys.env`) |

## Где взять ключи

**Ozon**
- Seller API: личный кабинет Ozon → Настройки → API-ключи → «Сгенерировать ключ». Нужны Client ID и сам ключ.
- Performance API (реклама): личный кабинет → Продвижение → Performance API → создать аккаунт.
  Нужны client_id и client_secret. Без них работает всё, кроме рекламы.

**Wildberries**
- Личный кабинет WB → Настройки → Доступ к API → «Создать новый токен». Тип — «Персональный».
- Отметьте **«Только на чтение»** и категории: Контент, Аналитика, Цены и скидки, Статистика, Продвижение.

## Что умеют

### Ozon

| Инструмент | Что даёт |
|---|---|
| `ozon_check` | Проверка ключей, связи и подписки кабинета |
| `ozon_products` | Список товаров: артикул, SKU, цена, остаток FBO/FBS, статус |
| `ozon_stocks` | Остатки FBO и FBS, по желанию — FBO по кластерам с оборачиваемостью |
| `ozon_orders` | Заказы, штуки, сумма и отмены по отправлениям FBO и FBS, до 31 дня за раз |
| `ozon_funnel` | Воронка: показы, сессии, корзины, штуки, выручка по дням или товарам |
| `ozon_product_content` | Контент карточки: характеристики с названиями, описание, фото, габариты, склейка |
| `ozon_ads_campaigns` | Рекламные кампании и их бюджеты |
| `ozon_ads_stats` | Расход, показы, клики, CTR, заказы и ДРР по кампаниям или дням |

### Wildberries

| Инструмент | Что даёт |
|---|---|
| `wb_check` | Проверка токена: категории, «только чтение», срок действия, связь |
| `wb_products` | Карточки: артикул, nmID, склейка, предмет, цена, скидка |
| `wb_product_content` | Контент карточки: характеристики, описание, фото и видео, размеры, габариты |
| `wb_stocks` | Остатки на складах WB и у продавца, в пути; по желанию — по складам |
| `wb_orders` | Заказы: штуки, суммы по цене продавца и покупателя, отмены, до 31 дня |
| `wb_sales` | Выкупы и возвраты, к перечислению до логистики, до 31 дня |
| `wb_funnel` | Воронка: переходы, корзины, заказы, выкупы, конверсии, сравнение с прошлым периодом |
| `wb_ads` | Реклама: списания, показы, клики, CTR, CPC, заказы, ДРР |
| `wb_finance` | Финансовый отчёт: к перечислению, логистика, хранение, штрафы, удержания, итог к выплате |

## Ограничения, о которых надо знать

**Ozon**
- Полная воронка (показы, корзины) доступна только кабинетам с подпиской Premium Plus.
  Без неё Ozon отдаёт по API только выручку и штуки. Это ограничение Ozon, а не плагина.
- Метод воронки сильно лимитирован: не чаще раза в минуту, без подписки около 50 вызовов в сутки.
- Сумма в заказах — это цена товара в отправлении, а не деньги к выплате.
- Кампании «Оплата за заказ» в статистике рекламы показывают расход, но заказы у них нули:
  Ozon отдаёт их отдельным отчётом.

**Wildberries**
- Лимиты WB жёсткие и общие на продавца: заказы, продажи, финотчёт и статистика рекламы — около запроса в минуту.
  Если WB просит подождать, плагин скажет, сколько. Повторять раньше нельзя — это продлевает ограничение.
- Заказы и продажи WB хранит около 90 дней.
- Заказ ещё не продажа: выкуп виден позже, процент выкупа на свежих днях занижен.

**Общее**
- Компьютер должен быть включён, пока вы работаете: сервер живёт только вместе с Claude Code.

## Если что-то не работает

- **«Нет ключей» / «Нет токена»** — файл не заполнен или лежит не там. Запустите команду настройки ещё раз.
- **HTTP 401** — ключ неверный, скопирован не целиком или истёк. Выпустите новый.
- **HTTP 403** — у ключа не хватает прав. На WB — не отмечена нужная категория токена.
- **Ошибка сети** — проверьте интернет и VPN.
- **HTTP 429 / «подождите N мин»** — лимит запросов. Подождите указанное время.
- **Инструменты не видны в Claude Code** — проверьте `node -v` и перезапустите Claude Code.

## В других программах

Серверы плагинов — обычные MCP-серверы без зависимостей. Их можно подключить в Codex CLI, Cursor, VS Code
и Claude Desktop, указав в настройках команду `node <путь>/plugins/ozon-api/server/index.js`
или `node <путь>/plugins/wb-api/server/index.js`. Скиллы с правилами чтения цифр и команды настройки
работают только в Claude Code.

В ChatGPT в браузере и в приложении локальный сервер подключить нельзя: ChatGPT принимает только
серверы с публичным адресом в интернете.
