# Плагин «Ozon API» для Claude Code

Подключает Claude Code к вашему магазину на Ozon. После установки можно спрашивать в чате обычными словами:
«какие остатки по FBO и FBS», «сколько заказов было на прошлой неделе», «покажи воронку по дням»,
«выгрузи характеристики и описание артикула 12.34», «как отработала реклама за неделю».

Плагин **только читает** данные. Цены, ставки, карточки и остатки он не меняет.

## Как это устроено

```
Claude Code ──► локальный сервер плагина (Node.js на вашем компьютере) ──► api-seller.ozon.ru
                                                                       └─► api-performance.ozon.ru
```

Сервер запускается сам вместе с Claude Code и работает на вашем компьютере. Ключи Ozon лежат в файле
на вашем компьютере. В чат они не попадают и никуда, кроме Ozon, не отправляются.
Полные ответы Ozon сохраняются в папку `ozon-data` в вашей домашней папке, в чат приходит сводка.

## Что нужно

- Claude Code (нужна платная подписка Claude Pro или выше).
- Node.js 18 или новее: скачать LTS-версию с nodejs.org. Проверка — команда `node -v` в терминале.
- Ключ Seller API из личного кабинета Ozon. Для рекламы — ещё ключ Performance API.

## Установка

В Claude Code выполните две команды:

```
/plugin marketplace add <ссылка на репозиторий или путь к папке с плагином>
/plugin install ozon-api@ozon-kurs
```

Перезапустите Claude Code, затем выполните:

```
/ozon-api:ozon-setup
```

Claude создаст файл для ключей и откроет его. Впишите ключи **в файл**, а не в чат, сохраните и напишите «готово».
Claude проверит подключение.

Файл ключей: `~/.ozon-plugin/keys.env` (на Windows — `C:\Users\<имя>\.ozon-plugin\keys.env`).

## Где взять ключи

- **Seller API:** личный кабинет Ozon → Настройки → API-ключи → «Сгенерировать ключ».
  Нужны Client ID и сам ключ.
- **Performance API (реклама):** личный кабинет → Продвижение → Performance API → создать аккаунт.
  Нужны client_id и client_secret. Без них работает всё, кроме рекламы.

## Что умеет

| Инструмент | Что даёт |
|---|---|
| `ozon_check` | Проверка ключей, связи и подписки кабинета |
| `ozon_products` | Список товаров: артикул, SKU, цена, остаток FBO/FBS, статус |
| `ozon_stocks` | Остатки FBO и FBS, по желанию — FBO по кластерам с оборачиваемостью |
| `ozon_orders` | Заказы, штуки, сумма и отмены по отправлениям FBO и FBS, до 31 дня за раз |
| `ozon_funnel` | Воронка: показы, сессии, корзины, штуки, выручка по дням или товарам |
| `ozon_product_content` | Контент карточки: характеристики с названиями, описание, фото, габариты, склейка |
| `ozon_ads_campaigns` | Рекламные кампании и их бюджеты |
| `ozon_ads_stats` | Расход, показы, клики, CTR, заказы и ДРР по кампаниям или дням |

## Ограничения, о которых надо знать

- Полная воронка (показы, корзины) доступна только кабинетам с подпиской Premium Plus.
  Без неё Ozon отдаёт по API только выручку и штуки. Это ограничение Ozon, а не плагина.
- Метод воронки сильно лимитирован: не чаще раза в минуту, без подписки около 50 вызовов в сутки.
- Сумма в заказах — это цена товара в отправлении, а не деньги к выплате.
- Кампании «Оплата за заказ» в статистике рекламы показывают расход, но заказы у них нули:
  Ozon отдаёт их отдельным отчётом.
- Компьютер должен быть включён, пока вы работаете: сервер живёт только вместе с Claude Code.

## Если что-то не работает

- **«Нет ключей»** — файл ключей не заполнен или лежит не там. Запустите `/ozon-api:ozon-setup`.
- **HTTP 401 / 403** — ключ неверный или без нужных прав. Перевыпустите ключ в личном кабинете.
- **Ошибка сети** — проверьте интернет и VPN.
- **HTTP 429** — Ozon просит подождать. Плагин сам повторяет запрос; если лимит суточный, попробуйте завтра.
- **Инструменты не видны в Claude Code** — проверьте `node -v` и перезапустите Claude Code.

## В других программах

Сервер плагина — обычный MCP-сервер без зависимостей. Его можно подключить в Codex CLI, Cursor, VS Code
и Claude Desktop, указав в их настройках команду `node <путь>/plugins/ozon-api/server/index.js`.
Скилл с правилами чтения цифр и команда настройки работают только в Claude Code.

В ChatGPT в браузере и в приложении локальный сервер подключить нельзя: ChatGPT принимает только
серверы с публичным адресом в интернете.
